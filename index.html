Cara pakai

Seret file dari Explorer langsung ke slot bernomor, atau ke area kanvas untuk susun berurutan. Klik slot untuk pilih file. Tempel dengan Ctrl+V. Geser foto di dalam sel untuk pan, scroll / slider untuk zoom, klik 2× untuk reset.

Atur ukuran kotak: garis antar kotak = pembatas kolom/baris, tarik untuk atur cepat. Handle di tepi kotak = atur kolom/baris; handle sudut = lepas jadi kotak bebas. Atau klik tombol ⤢ di toolbar foto untuk lepas jadi kotak bebas, ⤺ untuk kembalikan ke pola. Handle & garis selalu terlihat samar, penuh saat disentuh/dipilih.

Halaman: tombol besar ＋ Tambah Halaman Baru di bawah kanvas. Tiap halaman bisa diganti pola/orientasi, +Halaman paksa baru, 🗑 hapus halaman kosong.
